# Reports

Publication-ready figures and tables. This is the **single source of
truth** for the LaTeX manuscript: `\graphicspath{{../../reports/figures/}}`.

## Figure / table naming
- Figures: `figNN_<slug>.pdf` (also `.png` for dashboards)
- Tables: `tblNN_<slug>.{csv,md,tex}` (triple format: open, human, LaTeX)

The `NN` prefix matches the figure/table number used in the manuscript.
