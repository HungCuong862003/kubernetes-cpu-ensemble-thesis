# Submission snapshots

**Frozen, read-only** archival copies of the project at submission deadlines.

Do NOT edit anything in this folder. Generated by:
```bash
make archive DATE=YYYY-MM-DD LABEL=<label>
```

Each snapshot includes: data/processed, results/, reports/, src/, docs/,
thesis/ (with compiled PDF), and a `MANIFEST.md` with SHA-256 per file.
